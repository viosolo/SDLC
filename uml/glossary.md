
# Глоссарий проекта

| Термин | Определение |
| :--- | :--- |
| **Актер (Actor)** | Роль, которую играет пользователь или внешняя система по отношению к интернет-магазину (например, Покупатель или Администратор). |
| **Прецедент (Use Case)** | Последовательность действий, выполняемых системой в ответ на событие от актера для достижения конкретной цели (например, «Оформить заказ»). |
| **Ассоциация (Association)** | Базовая связь между актером и прецедентом, показывающая, кто инициирует действие. Обозначается сплошной линией. |
| **Включение (Include)** | Связь между прецедентами, показывающая, что один прецедент обязательно включает функционал другого (например, «Оформить заказ» обязательно включает «Добавить в корзину»). |
| **Состояние (State)** | Ситуация в жизненном цикле объекта, во время которой он удовлетворяет определенному условию или ожидает события (например, статус заказа «Новый» или «В обработке»). |
| **Покупатель** | Актер, который просматривает каталог, формирует корзину и оформляет заказы на сайте кондитерской. |
| **Администратор** | Актер, который управляет ассортиментом товаров и обрабатывает входящие заказы. |
| **Корзина** | Виртуальный контейнер, хранящий выбранные товары до момента оформления заказа. |
| **Заказ** | Сущность, создаваемая после подтверждения корзины клиентом и содержащая данные о доставке и составе. |
| **Система лояльности** | Механизм начисления бонусных баллов пользователям за совершенные покупки (REQ-FUNC-014). |
