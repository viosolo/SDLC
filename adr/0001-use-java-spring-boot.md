# Выбор Java Spring Boot для Backend

## Контекст и постановка задачи
Для проекта интернет-магазина «Viosolocake» необходимо создать надежный, безопасный REST API, который будет обрабатывать заказы, управлять каталогом товаров и обеспечивать безопасность пользовательских данных.

## Драйверы решения
* Безопасность (защита персональных данных, согласно `REQ-SEC-001`).
* Строгая типизация для снижения количества ошибок на этапе компиляции.
* Наличие готовых модулей для работы с базой данных.

## Рассмотренные варианты
* Node.js + Express
* Python + Django
* Java + Spring Boot

## Итог решения
Выбран вариант **«Java + Spring Boot»**, так как он обеспечивает наилучший баланс между безопасностью и зрелостью экосистемы.

### Последствия
* **Хорошо**, потому что встроенный модуль Spring Security закрывает требования по защите данных, а Spring Data JPA упрощает работу с БД.
* **Плохо**, потому что разработка на Java требует больше времени из-за необходимости писать boilerplate-код.

### Подтверждение
Проверка осуществляется через Code Review (архитектурный аудит) и запуск автотестов безопасности.

## Плюсы и минусы вариантов

### Node.js + Express
* Хорошо, потому что высокая скорость асинхронной обработки запросов.
* Плохо, потому что слабая типизация (даже с TypeScript) и меньше встроенных механизмов безопасности.

### Python + Django
* Хорошо, потому что быстрая разработка (батарейки в комплекте).
* Плохо, потому что ниже производительность при высоких нагрузках.

### Java + Spring Boot
* Хорошо, потому что строгая типизация, надежность и масштабируемость.
* Плохо, потому что более высокий порог входа и объем кода.

## Дополнительная информация

* Связанные элементы SDD: `002-composition`.
